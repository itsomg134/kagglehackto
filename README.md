# 🏃 Fast Boy Runner Game

A fun and addictive endless runner game built with Python and Pygame! Jump, dodge obstacles, collect coins, and see how long you can survive!

## 🎮 Game Features

- **Endless Runner Gameplay** - Test your reflexes as obstacles keep coming
- **Simple Controls** - Just press SPACEBAR to jump
- **Collectible Coins** - Grab golden coins for bonus points
- **Dynamic Obstacles** - Randomly generated red spiked obstacles
- **Score Tracking** - Keep track of your best runs
- **Smooth Physics** - Realistic jumping and gravity mechanics
- **Colorful Graphics** - Simple but charming pixel-style visuals
- **Instant Restart** - Press R to try again after game over

## 🚀 Getting Started

### Prerequisites

- Python 3.6 or higher
- Pygame library

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/fast-boy-runner.git
cd fast-boy-runner
```

2. Install required dependencies
```bash
pip install pygame
```

3. Run the game
```bash
python fast_boy.py
```

## 🎯 How to Play

1. **Press SPACEBAR** to make the character jump
2. **Avoid red spiked obstacles** - Colliding with them ends the game
3. **Collect yellow coins** - Each coin gives you +5 points
4. **Survive longer** - You earn +10 points for each obstacle you pass
5. **Press R** to restart after game over

## 🎨 Game Elements

- **Blue Character** - Your fast boy hero with a yellow head
- **Red Obstacles** - Dangerous spiked barriers to jump over
- **Yellow Coins** - Collectible bonus items
- **Green Ground** - The running surface
- **Blue Sky** - Background atmosphere

## 📊 Scoring System

- **+10 points** - For each obstacle successfully passed
- **+5 points** - For each coin collected
- **Coin counter** - Track total coins collected
